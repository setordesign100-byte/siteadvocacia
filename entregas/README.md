# Manual ilustrado do painel

[Baixar o manual em PDF](MANUAL-PAINEL-RTM.pdf).

O documento ensina a entrar no painel, alterar o próprio nome de usuário, trocar a senha, criar e revogar acessos de editores e preparar publicações, com prints e marcações numeradas.

O PDF inclui a credencial principal fornecida com o pacote. Por isso, ele é protegido com senha de abertura, entregue separadamente ao responsável na conversa. A senha de abertura e a versão sem proteção ficam fora do repositório.

Para acompanhar todos os passos, use a versão atualizada do [pacote do site](../SITE-RTM-LOCAWEB.zip), que inclui o botão **Alterar meu usuário**. Os dados e senhas já alterados pelo responsável no painel continuam valendo nas atualizações normais.

Este é um documento interno de orientação. O pacote enviado à hospedagem contém os arquivos do site; o manual não faz parte desse ZIP.
